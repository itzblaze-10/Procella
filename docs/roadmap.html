Traps found while testing

Month key 13
Each POWER year has keys 01 to 12 plus 13. Key 13 is the annual mean. Mixing it into a monthly series corrupts the trend, so we use it only as the annual value.
Fill value -999
Missing data arrives as -999. It becomes "missing" before any maths.
Different start years
Each variable starts at its own year. Surface solar radiation returned -999 for 1981. The app stores a first valid year per variable.
NDVI scaling
MODIS NDVI needs scale factor 0.0001 and ignores fill value -3000. Both were read from the service's band list.
Model, not instrument
POWER values come from MERRA-2 and CERES models. The app says so on every result, and one lat/lon means one grid cell of about 0.5 by 0.625 degrees.
3 · Collection

How the data gets into the app

The browser asks NASA directly. If that fails, the app falls back in a fixed order, so the demo works with no wifi and the page always says which data it is showing.

Live requestBrowser calls NASA POWER with an 8 second timeout.
Local cacheThe last good answer is kept in the browser, keyed by variable and place.
Committed snapshotA JSON file in the repo, written at build time by a script, for the curated places.
Badge"Live NASA POWER" or "Cached snapshot, with its date" sits next to every chart.

The request

https://power.larc.nasa.gov/api/temporal/monthly/point
  ?parameters=T2M,PRECTOTCORR&community=AG
  &latitude=23.22&longitude=72.65
  &start=1981&end=2025&format=JSON

The answer holds one value per month plus the annual mean for each year. Missing values are -999.

Build time

A script pulls POWER and ORNL for each curated place, applies the cleaning rules above and writes one JSON snapshot per place. The snapshots are committed, so a NASA outage cannot break the demo.

Visitors can still pick a new place. That request runs live and shows the Live badge, or an error message if NASA does not answer.

4 · The test

How a trend gets its verdict

Challenge wording: "determine whether these changes are significant". We use the Mann-Kendall test, which makes no assumption about the shape of the data.

Mann-Kendall
Compare every pair of years. Count pairs where the later year is higher, subtract pairs where it is lower. That count is S. A large positive or negative S means a steady direction. S becomes Z with a tie correction, and Z becomes a two-sided p.
Sen's slope
The median of the slope between every pair of years. It is the rate of change per year, and a few extreme years barely move it.
Verdict
Detected when p is below 0.05 and there are at least 15 years. Too short to judge under 15 years. Otherwise not detectable yet. "Not detectable" means the change cannot be told apart from yearly noise at this record length. It does not mean nothing changed.
Proof it works
S, Z, p and Sen's slope match pymannkendall to nine decimals on the live Gandhinagar series. A self-check ships with the script.
Not built yet
A confidence interval on the slope and a correction for year-to-year correlation. Both go into the app's engine.
python3 scripts/trend.py --selftest
python3 scripts/trend.py --lat 23.22 --lon 72.65 --param PRECTOTCORR --start 1981 --end 2025

6 · Giovanni path

The manual route the brief describes

Giovanni is NASA's own plotting tool and the brief points to it. Menu names below come from memory of the Giovanni guide, so we confirm them on screen once you are signed in.

  1. You sign in to NASA Earthdata in Chrome, then tell Claude. Claude never types the password.
  2. Open Giovanni and choose plot type Time Series, Area-Averaged.
  3. Search the variable. Examples: MERRA-2 2-meter air temperature, or GPM monthly precipitation.
  4. Enter a bounding box around Gandhinagar, for example west 72.4, south 23.0, east 72.9, north 23.4.
  5. Set the dates to January 1981 through December 2025 for monthly products.
  6. Choose Plot Data to preview, then download the CSV.
  7. Run the CSV through the same Mann-Kendall and Sen's slope code. A CSV input mode for scripts/trend.py is a small addition.
Giovanni averages a box. NASA POWER returns one grid cell. If both are run for the same place, expect small differences and say which one a result used.
